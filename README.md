# NGCP-RF

This is the GitHub database for all code relating to Radio Frequency (RF) the Northrop Grumman Collaboration Project 2025-2026 Unmanned Ground Vehicle Emergency Response Unit (NGCP UGV-ERU). 

All current code being tested, edited, and optimized for RF related tasks such as singal acqusition, signal analysis, and target tracking will be under "Current Code".

All old code that have been retired or have been changed out will be categorized under "Old Code".

All code that have been written but yet to be tested will be under "testing code".

All code that have been developed for simulation purposes will be under "Simulation".

All code that have been created to integrate the RF system with the rest of the UGV will be under "integration".
